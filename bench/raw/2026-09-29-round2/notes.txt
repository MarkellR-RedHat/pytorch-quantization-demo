Round 2 test results - Sep 29, 2026

Phase B: Spec Decode (2x H200, TP2, 8B draft, 5 speculative tokens) + INT4_RH GPTQ (1x H200)

All tests ran on the same cluster node.
vLLM 0.18.0+rhaiv.14, PyTorch 2.10.0, NVIDIA H200, Driver 580.126.20

What worked:
- All 4 setups deployed successfully from canonical repo YAMLs
- INT4_RH (RedHatAI/Meta-Llama-3.1-70B-Instruct-quantized.w4a16) deployed via model/runtime pattern
  with storage-config secret - no gating issues
- Zero failed requests across all load test levels for all 4 variants
- All preset captures finished with "stop" (none hit the 1024 token cap)
- All benchmarks ran inside pods via vllm bench serve (no port-forward latency)
- lm_eval ran on the laptop via port-forward for accuracy tests

Flags/issues:
