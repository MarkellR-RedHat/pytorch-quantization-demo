    How does this work?

    Every bird runs the same 4,673-parameter network trained in PyTorch. BF16 keeps 16 bits per weight, FP8 keeps 8, and both INT4 birds keep 4. INT4 RTN rounds each weight to the nearest step, while INT4 AWQ first rescales the weights that matter most (the idea behind AWQ), and that small change is the difference on hard gaps.

    Spec Decode flies the BF16 network, but a tiny draft network guesses the next few moves and the big one checks them all at once. It keeps the moves it agrees with and replaces the first one it doesn't, which is why its path matches BF16 exactly.

    The load-test button sends a fixed prompt to a real Llama 3.1 70B deployment on vLLM (or, in simulated mode, replays timings measured on H200s). Nothing you type is ever sent anywhere.
