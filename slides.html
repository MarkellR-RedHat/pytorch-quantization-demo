Wrap-up

What to take home 🧳

The points we made

  1. INT4 is a cost tool. One H200 per replica instead of two. Under heavy load it served about the same tokens per GPU as BF16, so the saving is the smaller replica.
  2. Spec decode is a latency tool. About 1.25× faster for one request on the same GPUs, and about half the tokens per GPU under load.
  3. Measure, don't guess. INT4 matched BF16 on 1,319 GSM8K problems and scored 3 points lower on 280 MMLU-Pro questions, too few to call it, so test yours.
  4. A router lets each one run where it's best, once your traffic is big and mixed enough to run more than one.

🤔 Things to think about

  • How much of your traffic really needs full precision?
  • Is your traffic big enough to justify more than one pool?
  • Is your target cost per token, or time to answer?
  • Do you have an eval set built from real prompts?
